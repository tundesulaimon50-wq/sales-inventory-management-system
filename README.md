Sales & Inventory Management System (SIMS)

Project Overview

An Excel-based Sales and Inventory Management System designed to help small businesses track sales, inventory, products, and business performance efficiently.

Key Features

- Daily sales tracking
- Inventory management
- Product master list
- Sales and profit calculations
- KPI dashboard
- Low-stock monitoring
- Automated calculations
- User-friendly interface

Tools Used

- Microsoft Excel
- Excel formulas
- Pivot Tables
- Data validation
- Dashboard & KPI reporting

Project Objective

The objective of this project is to provide small businesses with a simple and efficient system for managing sales and inventory while reducing manual calculations and improving business decision-making.
